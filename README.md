# Breakout 3D

> 一款基于 Raylib 的 3D 打砖块游戏，支持双人联机、道具系统、多关卡存档

---

##  项目简介

Breakout 3D 是经典打砖块游戏的现代化实现，采用 C++17 和 Raylib 图形库开发。玩家控制底部挡板反弹小球，击碎屏幕上方砖块。游戏包含丰富的道具系统、多关卡选择、排行榜以及多人联机功能。

### 核心特性

| 特性 | 说明 |
|------|------|
|  基础打砖块 | 经典玩法，控制挡板反弹小球 |
|  双人联机 | 基于 ENet 的多人对战模式 |
|  道具系统 | 3种强力道具（加长板、多球、减速球） |
|  多关卡存档 | 自动保存游戏进度，支持3个难度关卡 |
|  排行榜 | 本地高分记录系统 |
|  粒子特效 | 砖块破碎和道具掉落特效 |
|  配置驱动 | JSON 配置文件，可自由调整参数 |
|  性能优化 | 对象池 + 空间划分，支持大量粒子 |

##  编译运行

### 环境要求

| 依赖 | 版本要求 | 安装命令 (Ubuntu/Debian) |
|------|---------|-------------------------|
| CMake | >= 3.10 | `sudo apt install cmake` |
| Raylib | >= 4.0 | `sudo apt install libraylib-dev` |
| C++ 编译器 | C++17 (GCC 7+ / Clang 5+) | `sudo apt install build-essential` |
| ENet | >= 1.3 (可选，联机用) | `sudo apt install libenet-dev` |

### 编译运行步骤

```bash
# 1. 克隆或进入项目目录
cd Breakout_3D

# 2. 创建并进入构建目录
mkdir build && cd build

# 3. 配置 CMake
cmake ..

# 4. 编译游戏
make -j$(nproc)

# 5. 运行游戏
./breakout_game

### 运行选项
./breakout_game              # 单人模式
./breakout_game --host       # 创建联机房间
./breakout_game --client <IP> # 加入联机房间
./breakout_game --help       # 显示帮助信息

### 操作说明
```bash
按键        功能          说明
← / →      移动挡板      左右移动底部挡板
Shift+←/→  加速移动      按住 Shift 可加速移动挡板
空格        发射小球      游戏开始时发射小球
P           暂停游戏      暂停/继续游戏
R           重新开始      重新开始当前关卡
L           查看排行榜    显示最高分记录
F5          手动保存      手动保存当前游戏进度
G           切换优化模式  对比空间划分性能差异
ESC         退出游戏      退出到桌面


### 功能列表
# 1. 基础打砖块
经典玩法：控制挡板反弹小球击碎砖块
计分规则：每击碎一个砖块获得 10 分（受分数倍率影响）
生命机制：小球掉落底部损失一条生命，并扣除 50 分
过关条件：击碎所有砖块即可过关
# 2. 双人联机
网络库：基于 ENet 库的网络对战
主机模式：./breakout_game --host
客户端模式：./breakout_game --client <服务器IP>
同步机制：实时同步双方挡板位置和球的位置，支持客户端插值平滑显示对手动作
# 3. 道具系统
| 道具 | 图标 | 效果 | 持续时间 | 掉落率权重 |
| :--- | :--- | :--- | :--- | :--- |
| 加长板 | ↔️ 绿色 | 挡板宽度增加 40px | 5 秒 | 35% |
| 多球 | ● 橙色 | 增加 2 个小球 | 永久 | 30% |
| 减速球 | 🐌 蓝色 | 小球速度降低 40% | 4 秒 | 35% |

# 4.多关卡存档
关卡选择界面：
| 关卡 | 名称 | 难度 | 球速倍率 | 挡板速度倍率 | 初始生命 | 分数倍率 | 道具掉落率 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | Forest Valley | 简单 | 0.8x | 1.0x | 4 | 1x | 25% |
| 2 | Pyramid Peak | 普通 | 1.0x | 1.0x | 3 | 2x | 35% |
| 3 | Dark Castle | 困难 | 1.25x | 1.2x | 2 | 3x | 45% |

#存档功能：
·游戏自动保存进度（通关后保存下一关）
·按 F5 手动保存游戏
·游戏结束时自动删除存档
·菜单界面按 L 键可继续上次游戏
# 5. 排行榜
·本地存储最高 10 条记录
·自动判断新记录是否上榜
·游戏结束时显示排名
·按 L 键随时查看
# 6. 粒子特效
·砖块破碎时产生 12 个彩色粒子
·道具掉落时产生光晕粒子效果
·粒子系统使用对象池优化，支持 500 个粒子同时存在

# 7. 性能优化
| 技术 | 说明 | 效果 |
| :--- | :--- | :--- |
| 对象池 | 粒子系统使用静态数组预分配 | 避免动态内存分配 |
| 空间划分 | 网格法划分碰撞区域 | 减少碰撞检测次数 |
| 切换按键 | 按 `G` 键 | 可在游戏中切换优化模式对比性能差异 |
